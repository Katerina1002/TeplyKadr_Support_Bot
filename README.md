# 📸 TeplyKadr Support Bot

Официальный Telegram-бот поддержки и бронирования для ИП «Фотомастерская "ТЁПЛЫЙ КАДР"».  
Разработан в рамках курсового проекта по дисциплине «Основы проектной деятельности» (ГУАП, кафедра № 41).

## ✨ Основной функционал
- **Интерактивное Inline-меню:** удобная навигация по услугам, ценам и съёмочным локациям.
- **Просмотр залов с фотографиями:** «Винтаж», «Светлый лофт».
- **Онлайн-бронирование:** пошаговая запись клиента с сохранением в базу данных и моментальным уведомлением администратора в Telegram.
- **Отзывы и аналитика:** сбор оценок пользователей (1–5★) и автоматический расчёт среднего рейтинга студии.
- **Раздел FAQ:** ответы на популярные вопросы клиентов.

## 🛠 Стек технологий
- **Язык:** Python 3.14
- **Фреймворк:** `aiogram 3.x` (асинхронная работа с Telegram API)
- **База данных:** SQLite3
- **Безопасность:** хранение конфиденциальных ключей через `.env` (`python-dotenv`)

## 🚀 Установка и запуск
1. Клонируйте репозиторий:
   `git clone https://github.com/Katerina1002/TeplyKadr_Support_Bot.git`
2. Установите зависимости:
   `pip install -r requirements.txt`
3. Создайте файл `.env` в корне проекта и укажите ваши данные:
   env

   BOT_TOKEN=ваш_токен_от_BotFather

   ADMIN_ID=ваш_telegram_id
4. Запустите бота:
   `python main.py`
